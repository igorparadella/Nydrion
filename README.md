# Nydrion

**Sistema de gestão para nutricionistas, desenvolvido com foco em privacidade, autonomia e praticidade.**

O **Nydrion** é uma aplicação desenvolvida para auxiliar nutricionistas na organização e gestão de sua rotina profissional. O sistema reúne ferramentas para criação e gerenciamento de **planos alimentares**, **cadastro e acompanhamento de pacientes**, **organização da agenda de consultas** e outras funcionalidades voltadas à prática nutricional.

O projeto foi desenvolvido com a proposta de ser **simples, adaptável e acessível**, permitindo que cada profissional utilize o sistema de acordo com sua própria rotina de trabalho.

---

## 🥗 Principais funcionalidades

* 👤 **Gerenciamento de pacientes**

  * Cadastro e organização das informações dos pacientes.
  * Acompanhamento de dados relevantes ao atendimento.

* 🍎 **Planos alimentares**

  * Criação e gerenciamento de planos alimentares.
  * Organização das informações de acordo com a necessidade de cada paciente.

* 📅 **Agenda de consultas**

  * Organização dos compromissos e consultas.
  * Visualização e gerenciamento da rotina profissional.

* 📊 **Acompanhamento**

  * Registro e organização de informações relacionadas à evolução dos pacientes.
  * Estrutura pensada para facilitar o acompanhamento ao longo do tempo.

* ⚙️ **Personalização**

  * O sistema foi desenvolvido para se adaptar à forma de trabalho de cada profissional.
  * A estrutura permite a expansão e inclusão de novas funcionalidades conforme as necessidades do usuário.

---

## 🔐 Privacidade e segurança

A privacidade das informações é um dos principais objetivos do Nydrion.

O sistema foi projetado para funcionar **sem depender de um servidor externo ou de uma conexão permanente com a internet**. Dessa forma, os dados utilizados pelo profissional permanecem armazenados **localmente no computador em que o sistema está sendo utilizado**.

Além disso, o Nydrion utiliza **criptografia para proteção das informações armazenadas**, adicionando uma camada adicional de segurança aos dados.

Essa arquitetura reduz a necessidade de transmissão de informações para serviços externos e proporciona ao profissional maior controle sobre seus próprios dados.

> **Seus dados permanecem sob seu controle.**

---

## 💻 Sem dependência de servidor

Uma das características fundamentais do Nydrion é sua arquitetura local.

O sistema não exige a contratação ou manutenção de um servidor para funcionar. Isso proporciona algumas vantagens:

* Não há necessidade de manter um servidor online.
* O sistema pode funcionar sem conexão com a internet.
* Os dados permanecem armazenados localmente.
* Reduz-se a exposição de informações a serviços de terceiros.
* O profissional possui maior autonomia sobre seus dados.
* A utilização do sistema não depende da disponibilidade de um serviço externo.

Essa abordagem foi escolhida pensando especialmente em profissionais que desejam utilizar uma ferramenta de gestão sem precisar depender de uma infraestrutura online complexa.

---

## 🛡️ Segurança

O Nydrion foi desenvolvido considerando que informações relacionadas aos pacientes devem ser tratadas com responsabilidade.

A utilização de mecanismos de **criptografia e armazenamento local** busca proporcionar uma camada adicional de proteção às informações mantidas pelo sistema.

Entretanto, a segurança também depende do ambiente em que o software é utilizado. Recomenda-se manter o sistema operacional atualizado, utilizar mecanismos de autenticação adequados e realizar backups periódicos dos dados.

## 🧩 Desenvolvido para se adaptar

Cada profissional possui uma maneira diferente de organizar seus atendimentos.

Por esse motivo, o Nydrion não foi pensado como uma ferramenta rígida. Sua arquitetura busca permitir que o sistema seja **expandido, modificado e adaptado** conforme diferentes necessidades de utilização.

A proposta é oferecer uma base que possa evoluir junto com seus usuários, permitindo a implementação de novos recursos e melhorias ao longo do desenvolvimento do projeto.
